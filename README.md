# LOCKCODE

### [CloudFlare Pages](https://lockcode.pages.dev) * [GitHub Pages](https://zapl-corp.github.io/lockcode/) * [npm](https://www.npmjs.com/package/@zapl/lockcode)

Терминальный AI-агент в стиле opencode: пиксельный логотип, карточка сессии,
промпт `❯` и слэш-команды. Запросы уходят напрямую к провайдеру по OpenAI-совместимому
API — без прокси и посредников.

## Установка

```bash
npm install -g @zapl/lockcode
lockcode
```

Без глобальной установки:

```bash
npx @zapl/lockcode
```

Требуется Node.js 14 или новее. Имя команды в терминале — `lockcode`.

## Первый запуск

1. `lockcode` — выбрать язык (`ru` / `en`).
2. `/add` — провайдер → название модели → API-ключ.
3. Написать сообщение обычным текстом.

Ключ хранится локально в конфиге LOCKCODE, никуда кроме выбранного провайдера не уходит.

Пример сессии:

```
❯ объясни, что делает renderHeader
⋯ обращение к deepseek-chat…
● lockcode · agent · deepseek-chat — 412 ток.
Функция собирает шапку: рисует пиксельный логотип, теглайн и карточку сессии.
```

## Команды

| Команда | Действие |
| --- | --- |
| `/help` | список команд |
| `/add` | добавить модель: провайдер, имя, ключ |
| `/models` | модели SERVER и USER |
| `/model <имя>` | выбрать активную модель |
| `/mode [chat\|agent]` | режим работы |
| `/limits` | локальный расход лимитов |
| `/folder <путь>` | папка проекта |
| `/lang [ru\|en]` | язык интерфейса |
| `/clear` | очистить экран и контекст |
| `/exit` | выход |

`Ctrl+C` — выход, `↑` / `↓` — история ввода.

## Провайдеры

Поддерживаются OpenAI-совместимые API: OpenRouter, DeepSeek, OpenAI, Mistral, Gemini,
а также любой свой эндпоинт через пункт `Custom` (нужен базовый URL вида `https://host/v1`).

## Нейросеть в репозитории
Нейросеть в данном репозитории будет использоваться исключительно для рейтинга кода, по 10 бальной системе, и небольших правок кода, но никак не для полноценного вайбкодерства обновления

## Где лежит конфиг

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\lockcode-nodejs\Config\config.json` |
| macOS | `~/Library/Application Support/lockcode-nodejs/Config/config.json` |
| Linux | `~/.config/lockcode-nodejs/config.json` |

Ключи лежат в этом файле открытым текстом — не выкладывайте его в репозиторий.

## Ограничения

- Ответ приходит целиком, без потоковой выдачи.
- Agent-режим пока не редактирует файлы и не запускает тесты.
- `/limits` показывает локальные счётчики, а не данные провайдера.
