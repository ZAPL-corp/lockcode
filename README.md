# LOCKCODE

### [CloudFlare Pages](https://lockcode.pages.dev) * [GitHub Pages](https://zapl-corp.github.io/lockcode/) * [npm](https://www.npmjs.com/package/@zapl/lockcode)

Терминальный AI-агент в стиле opencode: пиксельный логотип, карточка сессии,
промпт `❯` и слэш-команды. Запросы уходят напрямую к провайдеру по OpenAI-совместимому
API — без прокси и посредников.

## Установка

```bash
npm install -g @zapl/lockcode
```
Запуск из любой директории:
```bash
lockcode
```

Без глобальной установки:

```bash
npx @zapl/lockcode
```

Требуется Node.js 14 или новее. Имя команды в терминале — `lockcode`.

## Первый запуск

1. Введите в теминал команду `lockcode`
2. `/add` — провайдер → название модели → API-ключ.
3. Написать сообщение обычным текстом.

Ключ хранится локально в конфиге LOCKCODE, никуда кроме выбранного провайдера не уходит.

Пример сессии:

```
                  User: Что такое GPT?

                  AI: GPT (Generative Pre-trained Transformer) — это тип нейросетевой
                  архитектуры и семейство языковых моделей, которые генерируют и понимают
                  текст.

                  Ключевые моменты:
                  • Генеративная: создаёт новый текст (ответы, код, статьи), а не только
                    классифицирует готовый.
                  • Предобученная: сначала обучается на огромном массиве текстов, усваивая
                    закономерности языка и факты.
                  • Transformer: использует архитектуру «трансформер» с механизмом внимания
                    (attention) для учёта контекста в длинных последовательностях.
                  • Токены и вероятности: текст разбивается на токены; модель предсказывает
                    следующий токен по вероятности, повторяя это шаг за шагом.
                  • Инструкции и RLHF: после предобучения дообучают на инструкциях и с
                    помощью обратной связи от людей (RLHF), чтобы ответы были полезнее и
                    безопаснее.
                  • Контекстное окно: модель «видит» ограниченный объём токенов диалога; всё
                    за пределами окна забывается в рамках сессии.
                  • Сильные стороны: связная речь, программирование, суммаризация,
                    объяснение сложных тем простым языком.
                  • Ограничения: возможны галлюцинации (ложные, но правдоподобные
                    утверждения), зависимость от данных обучения, нет «понимания» как у
                    человека, знания ограничены датой обучения.

                  Если нужно, могу привести примеры, где GPT особенно полезен, или объяснить
                  разницу между версиями (например, GPT-3.5, GPT-4) простыми словами.
                  ──────────────────────────────────────────────────────────────────────────
                  DeepSeek V4.1 : 322 токенов
```

## Команды

| Команда | Действие |
| --- | --- |
| /help | Список вспомогательных команд |
| /mode | Выбрать режим работы модели |
| /modeagent | Выбрать режим работы агента |
| /submodels | Модели провайдера и переключение |
| /server | Общий прокси вместо локального ключа |
| /models | Список доступных моделей |
| /add | Добавить модель по API |
| /model <имя> | Выбрать модель |
| /model -del <имя> | Удалить модель из списка |
| /chat | Выбрать чат из списка |
| /cleanmemory | Очистить память |
| /connectors | Доступ к сервисам |
| /keyfile | Взять ключ из сервера |
| /limits | Узнать лимиты моделей |
| /folder | Сменить рабочую директорию |
| /lang | Сменить язык |
| /clear | Очистить строку состояния |
| /exit | Завершить работу |

`Ctrl+C` — выход, `↑` / `↓` — история ввода.

## Провайдеры

Поддерживаются OpenAI-совместимые API: OpenRouter, DeepSeek, OpenAI, Mistral, Gemini, GigaChat, 
а также любой свой эндпоинт через пункт `Custom` (нужен базовый URL вида `https://host/v1`).

## Где лежит конфиг

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\lockcode-nodejs\Config\config.json` |
| macOS | `~/Library/Application Support/lockcode-nodejs/Config/config.json` |
| Linux | `~/.config/lockcode-nodejs/config.json` |

Ключи лежат в этом файле открытым текстом — не выкладывайте его в репозиторий.
